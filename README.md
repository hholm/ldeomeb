# LDEO MEB Lab Custom Functions
An R package of functions used for data processing in the LDEO MEB lab. https://hurley.ldeo.columbia.edu/

To install, from R run:
```remotes::install_github("hholm/ldeomeb")```

Currently includes function for pH determination on a TECAN plate reader:
- `tidyplate()`	- Import and format plate reader data from TECAN i-control.
- `calc_pH_spec()`	- Calculate pH values from m-cresol dye absorbance.
- `calc_plate()`	- Calculate pH values from m-cresol dye absorbance for an entire plate at once.

Also includes functions to perform calculations on fluorescence values: 
- `ft_convert` - Convert fluorescence values between instruments or excitation colors for a phytoplankton species.
- `average_turner` - Calculate mean of multiple files generated by a Turner Fluorometer (C-FLUOR) at once.
